# Sparkya — Sistema de Parqueo Automático

## Estructura del repositorio

```
sparkya-db/
  README.md
  docs/
    planteamiento.md
    requisitos-y-supuestos.md
    diccionario-de-datos.md
  diagramas/
    eer-sparkya.dot
    eer-sparkya.png
  entregas/
    entrega-1.pdf
```

- `docs/` — planteamiento, requisitos/supuestos y diccionario de datos en Markdown (fuente editable).
- `diagramas/` — diagrama EER. El `.dot` es el fuente (Graphviz); también se puede rehacer en draw.io/diagrams.net si el grupo lo prefiere.
- `entregas/` — el PDF final de cada entrega, tal como se sube a la plataforma del curso.
