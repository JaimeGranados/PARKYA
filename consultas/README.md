# Banco de consultas

`banco_consultas.sql` contiene las consultas de negocio de la Entrega 2. Cada una lleva un comentario con:

1. La pregunta de negocio que responde.
2. El requisito que cubre (RF1–RF9).
3. La técnica usada (join de 3+ tablas, LEFT JOIN, GROUP BY + HAVING, CTE, vista).
4. La verificación hecha a mano (qué se contó y qué dio).
