# Diccionario de datos inicial

El diccionario de datos completo (13 tablas: columna, tipo, nulabilidad y descripción de negocio) está en la sección 5 de `entregas/entrega-1.pdf`.

Este archivo se irá actualizando en Markdown a medida que el esquema evolucione en la Entrega 2, para no depender solo del PDF.

## Tablas del modelo

SEDE, ESPACIO, TIPO_VEHICULO, VEHICULO, CLIENTE, CLIENTE_OCASIONAL, CLIENTE_SUSCRIPTOR, PLAN_SUSCRIPCION, SUSCRIPCION, TARIFA, EMPLEADO, SESION, PAGO, INCIDENCIA.
